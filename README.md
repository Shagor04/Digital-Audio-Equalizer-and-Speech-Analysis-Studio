# Digital-Audio-Equalizer-and-Speech-Analysis-Studio
Digital audio equalizer in Python (Tkinter) built for CSE220 Signals &amp; Systems: 10-band FIR graphic EQ, IIR biquad parametric EQ, hum removal and spectral-gating noise reduction, and classical-DSP (no ML) voice separation, with live waveform, analysis tools, and built-in demo signals.
